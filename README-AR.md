# MN ULTRA — بناء سحابي لملف IPA

هذا المشروع يُبنى على GitHub Actions باستخدام جهاز macOS سحابي. الناتج **IPA غير موقّع**؛ افتحه في KSign واختر شهادة توقيع صالحة للتثبيت على جهازك.

## طريقة البناء من الآيفون

1. نزّل ZIP وفك ضغطه.
2. أنشئ مستودعًا جديدًا على GitHub من المتصفح.
3. ارفع محتويات هذا المجلد إلى المستودع، مع الحفاظ على مجلد `.github/workflows`.
4. افتح تبويب **Actions** في المستودع.
5. اختر **Build unsigned IPA** ثم **Run workflow**.
6. بعد انتهاء التشغيل بنجاح، افتح صفحة التشغيل وانزل إلى **Artifacts**.
7. نزّل `MN-ULTRA-unsigned-IPA`، وفك ضغط ملف الـ artifact لتحصل على `MN-ULTRA.ipa`.
8. افتح KSign واستورد ملف IPA، ثم وقّعه بشهادتك وثبّته.

## محتوى النسخة الحالية

- مكتبة محلية لاستيراد ملفات الفيديو والصوت من تطبيق «الملفات».
- تشغيل الملفات دون إنترنت.
- مشغّل AVPlayer.

## حدود مهمة

- هذه النسخة لا تجلب مقاطع YouTube ولا تزيل إعلانات YouTube.
- ملف IPA الناتج غير موقّع عمدًا؛ KSign يحتاج شهادة توقيع صالحة.
- لم يُختبر التثبيت على جهاز iOS فعلي. إعداد النشر المستهدف iOS 16 أو أحدث.
- لا ترفع شهادة التوقيع أو المفتاح الخاص أو كلمة مرور Apple إلى المستودع.
